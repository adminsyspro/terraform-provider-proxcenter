# ProxCenter Provider

The ProxCenter provider manages virtual machines through the [ProxCenter](https://proxcenter.io) public API v1, with a `pxc_` API token. It works with a provider token and with the token of a vDC tenant: quotas, allowed networks and the vDC boundaries stay enforced by ProxCenter.

The token needs `vms:read` and `vms:write`; `vms:power` to run VMs, `vms:delete` to destroy them, `vms:nic` to set a VLAN tag or a MAC address as a vDC tenant. The provider requires ProxCenter 1.5.0 or later and Terraform 1.11 or later (for the write-only cloud-init password).

## Example

```terraform
terraform {
  required_providers {
    proxcenter = {
      source = "adminsyspro/proxcenter"
    }
  }
}

# Endpoint and token can also come from PROXCENTER_ENDPOINT and PROXCENTER_TOKEN.
provider "proxcenter" {
  endpoint = "https://proxcenter.example.com"
  token    = var.proxcenter_token
}

variable "proxcenter_token" {
  type      = string
  sensitive = true
}
```
