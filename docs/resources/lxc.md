# proxcenter_lxc (Resource)

An LXC container managed through ProxCenter, created from a container template or by cloning a container. Quotas, allowed networks and vDC rules are enforced by ProxCenter; its refusals are shown as they are.

What ProxCenter lets change after creation is CPU, memory, swap, features, the hostname and the network cards; the root filesystem and mount points grow and move in place. Mount points, the root password, the SSH keys, the DNS settings and the privilege of a container are set at its creation only: changing them later is recorded with a warning and not applied. A vDC tenant may only create unprivileged containers: ProxCenter refuses `unprivileged = false`. A clone takes its privilege, password, keys and DNS settings from its source. Mount points are created included in backups. ProxCenter allocates no IPAM address to a container: set `ip` to an address of the network, or `dhcp` where a DHCP server answers.

## Example

```terraform
# A vDC tenant creates a container from a template of the cluster.
# The token needs vms:read and vms:write; vms:power to run it, vms:delete to
# destroy it.

data "proxcenter_vdc" "prod" {
  name = "prod"
}

resource "proxcenter_lxc" "web" {
  connection_id = data.proxcenter_vdc.prod.connection_id
  target_node   = data.proxcenter_vdc.prod.nodes[0]
  hostname      = "web-ct-01"

  source {
    ostemplate = "local:vztmpl/debian-13-standard_13.6-1_amd64.tar.zst"
  }

  cores     = 2
  memory_mb = 1024

  features = {
    nesting = true
  }

  rootfs {
    storage = data.proxcenter_vdc.prod.primary_storage
    size_gb = 8
  }

  mount_point {
    slot    = "mp0"
    storage = data.proxcenter_vdc.prod.primary_storage
    size_gb = 20
    path    = "/srv"
  }

  network {
    bridge  = "vnet-prod"
    ip      = "10.15.15.40/24" # ProxCenter allocates no IPAM address to a container
    gateway = "10.15.15.1"
  }

  ssh_keys = [file("~/.ssh/id_ed25519.pub")]

  power_state = "running"
}
```

## Schema

### Optional

> **NOTE**: [Write-only arguments](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments) are supported in Terraform 1.11 and later.

- `features` (Map of Boolean) Container features, e.g. { nesting = true }; unset keeps what the container has.
- `force_stop` (Boolean) Hard stop the container when a clean shutdown does not stop it.
- `mount_point` (Block List) Mount points by slot, set at creation; they grow and move in place. Adding or removing one after creation is refused at plan. (see [below for nested schema](#nestedblock--mount_point))
- `nameserver` (String) DNS server, set at creation only.
- `network` (Block List) Network cards by slot. Set slot on each block when there are several. A card no longer described is refused at plan. (see [below for nested schema](#nestedblock--network))
- `password_wo` (String, Sensitive, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) Root password, set at creation only and never stored in state (Terraform 1.11+).
- `power_state` (String) running or stopped; running at creation when unset, the container's state otherwise.
- `reboot_on_change` (Boolean) Reboot the container when a change waits for a reboot; false only warns.
- `rootfs` (Block, Optional) Root filesystem. It grows in place and moves when its storage changes; shrinking it is refused at plan. (see [below for nested schema](#nestedblock--rootfs))
- `search_domain` (String) DNS search domain, set at creation only.
- `source` (Block, Optional) Where the container comes from; required to create it, optional after an import. Changing it replaces the container. (see [below for nested schema](#nestedblock--source))
- `ssh_keys` (List of String) Public SSH keys for root, set at creation only.
- `swap_mb` (Number) Swap, MiB; 512 at creation when unset.
- `target_node` (String) Node to create the container on; required for an ostemplate source, defaults to the source's node for a clone. Ignored after creation.
- `timeouts` (Block, Optional) (see [below for nested schema](#nestedblock--timeouts))
- `unprivileged` (Boolean) Unprivileged container; true at creation when unset. Set at creation only; ProxCenter refuses false to a vDC tenant.
- `vmid` (Number) Unset: the next free VMID (inside the tenant range for a vDC tenant).

### Read-Only

- `id` (String) <connection_id>/<vmid>, also the import id.
- `node` (String) Node the container runs on, read back on every refresh.
