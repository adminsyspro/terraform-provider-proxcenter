# proxcenter_vm (Resource)

A QEMU VM managed through ProxCenter, created from the catalogue (image or blueprint) or by cloning a VM. Quotas, allowed networks and vDC rules are enforced by ProxCenter; its refusals are shown as they are.

Quotas, allowed networks and the other vDC rules are enforced by ProxCenter: a refusal is shown as ProxCenter wrote it. A disk only grows and a disk or a network card that is no longer described is refused at plan, so no change in the configuration destroys a VM by accident; only a different `source` replaces it.

## Example: from the catalogue

```terraform
# A vDC tenant deploys a VM from the catalogue granted to its vDC.
# The token needs vms:read and vms:write; vms:power to run it, vms:delete to
# destroy it, vms:nic to set a VLAN tag or a MAC address.

data "proxcenter_vdc" "prod" {
  name = "prod"
}

resource "proxcenter_vm" "web" {
  connection_id = data.proxcenter_vdc.prod.connection_id
  target_node   = data.proxcenter_vdc.prod.nodes[0]
  name          = "web-01"

  source {
    image = "debian-12"
  }

  cores     = 2
  memory_mb = 2048

  disk {
    slot    = "scsi0"
    storage = data.proxcenter_vdc.prod.primary_storage
    size_gb = 20
  }

  network {
    bridge = "v6bc065f" # pve_name of a VNet of the vDC (data.proxcenter_vnets)
  }

  cloud_init {
    user     = "ops"
    ssh_keys = [file("~/.ssh/id_ed25519.pub")]
  }

  power_state = "running"
}

output "web_address" {
  value = proxcenter_vm.web.cloud_init.ip_address
}
```

## Example: clone of a template

```terraform
# A clone of a template, placed on the template's node.
resource "proxcenter_vm" "app" {
  connection_id = data.proxcenter_vdc.prod.connection_id
  name          = "app-01"

  source {
    clone_of = 9000
  }

  cores     = 2
  memory_mb = 4096

  disk {
    slot    = "scsi0"
    storage = "ceph-gold"
    size_gb = 32
  }

  network {
    bridge = "vnet-prod"
  }

  power_state = "stopped"
}
```

## Schema

### Required

- `connection_id` (String) Cluster connection, e.g. data.proxcenter_vdc.x.connection_id.
- `cores` (Number) Cores per socket.
- `memory_mb` (Number) Memory, MiB.
- `name` (String) VM name.

### Optional

> **NOTE**: [Write-only arguments](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments) are supported in Terraform 1.11 and later.

- `cloud_init` (Block, Optional) Cloud-init settings. A field left unset keeps the value the VM has. (see [below for nested schema](#nestedblock--cloud_init))
- `cpu` (String) CPU model; unset keeps what ProxCenter set (vDC CPU policy).
- `disk` (Block List) Disks by slot. A disk grows in place, moves when its storage changes; shrinking or removing one is refused at plan. (see [below for nested schema](#nestedblock--disk))
- `force_stop` (Boolean) Hard stop the VM when an ACPI shutdown does not stop it.
- `network` (Block List) Network cards by slot. Set slot on each block when there are several. A card no longer described is refused at plan. (see [below for nested schema](#nestedblock--network))
- `power_state` (String) running or stopped; running at creation when unset, the VM's state otherwise.
- `reboot_on_change` (Boolean) Reboot the VM when a change waits for a reboot; false only warns.
- `sockets` (Number) Defaults to 1 at creation; unset keeps the VM's value.
- `source` (Block, Optional) Where the VM comes from; required to create it, optional after an import. Changing it replaces the VM. (see [below for nested schema](#nestedblock--source))
- `target_node` (String) Node to create the VM on; required for a catalogue source, defaults to the source's node for a clone. Ignored after creation.
- `timeouts` (Block, Optional) (see [below for nested schema](#nestedblock--timeouts))
- `vmid` (Number) Unset: the next free VMID (inside the tenant range for a vDC tenant).

### Read-Only

- `id` (String) <connection_id>/<vmid>, also the import id.
- `node` (String) Node the VM runs on, read back on every refresh (follows DRS).
